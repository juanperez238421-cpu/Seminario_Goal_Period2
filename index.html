Metas del periodo

Ruta 1

Consolidación funcional

Para estudiantes con ejercicios aislados o proyectos incompletos.

  1. Integrar HTML, JavaScript, eventos y DOM.
  2. Agregar validación, navegación y persistencia.
  3. Completar un flujo funcional de inicio a fin.
  4. Documentar y entregar commits verificables.
Ruta 2 · referencia

Especialización CSS

Para el proyecto con mayor integración funcional actual.

  1. Variables, arquitectura y componentes CSS.
  2. Grid, Flexbox y diseño responsive.
  3. Estados hover, focus, error y disabled.
  4. Accesibilidad, contraste y consistencia visual.
