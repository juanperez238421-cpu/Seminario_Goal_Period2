# Guías de Seminario — Periodo 2

Esta carpeta contiene las guías individuales generadas a partir del estado auditado de los repositorios vinculados.

## Documentos

- `pdf/guia_docente_preclase_2026_07_29.pdf`: orden de revisión y protocolo para la clase.
- `pdf/guia_proyecto_referencia_desde_cero.pdf`: estándar de proyecto y construcción explícita desde cero.
- `pdf/guia_<estudiante>.pdf`: estado actual, brecha frente al proyecto de referencia, plan de trabajo y evidencias requeridas.
- `tex/`: fuentes LaTeX editables.
- `seminario_guias_2026_07_29.zip`: paquete completo.
- `index.json`: índice consumido por `portfolio.html`.

## Criterio de evaluación

Los puntajes incluidos son estimaciones técnicas provisionales derivadas de evidencia observable en el repositorio. No sustituyen la ejecución, explicación, modificación en vivo ni comprobación de autoría.

Para proyectos en pareja:

- el estado técnico del repositorio puede ser común;
- la explicación, autoría, modificación en vivo y responsabilidad siguen siendo individuales;
- el README debe identificar integrantes, roles y estado del trabajo.

## Actualización automática

El workflow `Generate student PDF guides` vuelve a generar los documentos cuando cambia:

- el listado de estudiantes;
- el índice de proyectos auditados;
- un manifiesto de proyecto;
- el generador de guías.

También puede ejecutarse manualmente desde la pestaña **Actions**.
