# Política de proyectos individuales y en pareja

## Alcance del segundo periodo

Durante este periodo se permiten proyectos individuales o parejas de máximo dos estudiantes.

## Registro del equipo

La página `portfolio.html` permite vincular:

- integrante principal;
- segundo integrante;
- proyecto compartido;
- repositorio compartido;
- rol de cada integrante;
- meta semanal común.

La configuración se guarda primero en el navegador del docente y puede exportarse como JSON.

## Evidencia común

Los siguientes elementos pertenecen al repositorio y pueden tener una valoración técnica común:

- funcionamiento de la aplicación;
- estructura HTML;
- lógica JavaScript;
- DOM y eventos;
- CSS;
- persistencia;
- validaciones;
- integración del flujo;
- documentación general del proyecto.

## Evidencia individual

Cada integrante debe demostrar por separado:

- comprensión del código;
- autoría o responsabilidad concreta;
- modificación en vivo;
- explicación del recorrido de los datos;
- capacidad para corregir un error;
- commits propios o evidencia verificable de su aporte.

## README obligatorio

Todo repositorio compartido debe incluir:

```text
# Nombre del proyecto
## Integrantes
## Rol de cada integrante
## Objetivo
## Cómo ejecutar
## Flujo principal
## Estado actual
## Pendientes
```

## Cierre de la revisión

La nota técnica automatizada es provisional. Solo se consolida después de ejecutar el proyecto y verificar explicación, modificación en vivo y autoría de cada integrante.
